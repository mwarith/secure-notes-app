# Issue tracker: Linear.app

Issues and specs for this repo live as tickets in Linear.app, created via the web UI.

## Conventions

- Each ticket follows the template: Problem, Acceptance Criteria, Edge Cases, Testing Expectations, Branch name.
- Each ticket maps to one Git branch named `ENG-{n}-{slug}`.
- Ticket content is pasted directly into OpenCode prompts — no MCP integration is used.

## When a skill says "publish to the issue tracker"

The user creates the ticket manually in Linear (web UI) using the template.

## When a skill says "fetch the relevant ticket"

The user pastes the ticket content from Linear into the prompt.

## Wayfinding operations

Not applicable — Linear tickets are created manually and resolved by the user outside of agent workflows.
